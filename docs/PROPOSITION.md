# NEO Bureau — proposition (v0.1, 4 novembre 2026)

## Principe
- Deux Neo, deux rôles séparés : **Neo DUPLEX** (traduction, hors de ce projet) et **Neo Bureau** (ce projet).
- Le site est la « régie » : il configure les touches **et** joue le son sur le Mac. Le Neo n'est qu'une télécommande.
- Séparation garantie par le **numéro de série** : seul le Neo associé est piloté.
